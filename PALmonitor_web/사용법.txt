[PALmonitor 웹 앱 - 아주 쉬운 사용법]

폰에서 보조 PC 화면을 보고 제어합니다. 집 밖에서도 됩니다.
설정 입력 없이, 집에서는 배치파일 한 번만 더블클릭하면 끝입니다.

===========================================================================
■ 딱 두 가지만 하면 됩니다
===========================================================================

[집 PC에서 — 한 번만]
  1) 보조 PC에 auxiliary_server.py 가 평소처럼 실행 중인지 확인(기존 그대로).
  2) 이 폴더의  원격_켜기.bat  을 더블클릭.
     → 파이썬이 없으면 안내가 뜹니다(파이썬만 설치하고 다시 더블클릭).
     → "완료!" 가 뜨면 끝. 이제부터 이 PC는 켤 때마다 자동으로 연결됩니다.
     → 터미널/파이썬 창을 계속 띄워 둘 필요 없습니다. 창은 닫아도 됩니다.

[폰에서]
  1) 브라우저로  https://pmv.lagem1535.workers.dev  열기.
  2) (앱처럼 쓰기) 브라우저 메뉴 → "홈 화면에 추가".
  3) 이메일/비밀번호로 로그인 → 끝. 자동으로 화면이 뜹니다.
     ("연결 코드" 같은 건 입력할 필요 없습니다. 이미 자동입니다.)

===========================================================================
■ 처음 한 번만 필요한 준비 (이미 돼 있으면 건너뛰세요)
===========================================================================
  · Firebase 로그인 계정: 콘솔(fir-2-f3b80) → Authentication → "이메일/비밀번호"
    사용 설정 → Users 에서 로그인할 계정 추가.
  · Cloudflare 배포: 이 저장소가 Cloudflare 에 연결돼 배포돼 있어야 합니다
    (주소: https://pmv.lagem1535.workers.dev). 빌드가 빨간색이면 Retry build.

===========================================================================
■ 혹시 잘 안 되면
===========================================================================
  · 폰에서 "릴레이(집 PC) 기다리는 중…" 에서 안 넘어가면 → 집 PC에서
    원격_켜기.bat 을 다시 더블클릭(자동 연결이 꺼져 있을 수 있음).
  · 릴레이를 보조 PC가 "아닌" 다른 PC에서 돌린다면, 그 PC에서
    원격_켜기.bat 대신 아래처럼 보조 PC 주소를 한 번만 알려주세요:
        python relay_agent.py --install --aux_host 192.168.0.20
  · 자동 연결 끄기:  python relay_agent.py --uninstall

===========================================================================
■ 조작
  · 탭=클릭, 드래그=마우스 이동, 두 손가락 위/아래=스크롤
  · 상단 "⌨ OFF"→"ON" 누르면 키보드 입력 전달, "⛶" 전체화면
