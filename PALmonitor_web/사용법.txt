[PALmonitor 웹 앱 - 사용법 (앱/어디서나/터미널 안 띄움)]

폰에 "앱(PWA)"으로 설치해서, 집 밖에서도 보조 PC 화면을 보고 제어합니다.
파이썬 창을 계속 띄워 둘 필요가 없습니다(한 번 설치하면 부팅 시 자동 실행).

구조:
  폰(PWA)  <--wss-->  Cloudflare Worker(중계)  <--wss(밖으로)-->  집 릴레이  <--TCP-->  보조 PC

핵심: 집 릴레이가 "밖으로" Cloudflare에 접속하므로
  - 공유기 포트포워딩/인증서 필요 없음
  - 폰은 항상 https/wss(Cloudflare)로만 접속 → 앱 설치 가능, ws:// 차단 없음

===========================================================================
■ 1. Cloudflare에 배포 (한 번)
  - 이 저장소(PMV)를 Cloudflare Workers에 연결하고 "npx wrangler deploy" 로 배포.
    (이미 연결돼 있으면 Deployments 에서 Retry build)
  - 배포되면 주소가 생깁니다. 예) https://pmv.<서브도메인>.workers.dev
    → 이 주소가 "폰 앱 주소"이자 "릴레이가 붙을 Worker 주소"입니다.
  - (권장) 접속 보호를 위해 Worker에 HOST_KEY 비밀값을 설정:
      Cloudflare 대시보드 → 이 Worker → Settings → Variables and Secrets
      → Secret 추가:  이름 HOST_KEY,  값 = 길고 무작위인 문자열
    (설정하면 릴레이도 같은 key 를 써야 합니다. 안 하면 room 코드만으로 보호)

■ 2. Firebase 로그인 설정 (한 번)
  Firebase 콘솔(프로젝트 fir-2-f3b80) → 빌드 → Authentication → 시작하기
  → "이메일/비밀번호" 사용 설정 → Users 탭에서 로그인할 계정 추가
  (프로젝트 설정값은 web/firebase_config.js 에 이미 들어 있습니다)

■ 3. "연결 코드(room)" 정하기
  폰과 집 릴레이가 같은 코드를 쓰면 짝지어집니다. 이 코드가 사실상 비밀번호이므로
  길고 무작위로 정하세요. 예) a7f3c91b5e2d8 (아무 긴 문자열)

===========================================================================
■ 4. 집 릴레이 설치 (보조 PC 또는 같은 네트워크의 PC에서, 한 번)
  1) 보조 PC에는 auxiliary_server.py 가 평소처럼 실행 중이어야 합니다(TCP 58712).
  2) 릴레이를 돌릴 PC에서(보조 PC 자신이어도 됨):
        pip install websockets
  3) 설정 저장 + 자동시작 등록 + 바로 실행:
        python relay_agent.py --install ^
          --worker wss://pmv.<서브도메인>.workers.dev ^
          --room a7f3c91b5e2d8 ^
          --secret 1234
     (보조 PC가 다른 PC면  --aux_host <보조PC_IP>  추가,
      HOST_KEY 를 설정했으면  --key <그 값>  추가)
  → 이때 Windows 시작프로그램에 등록되어, 다음 부팅부터 콘솔 없이 자동 실행됩니다.
  → 즉, 이후로는 터미널/파이썬 창을 띄워 둘 필요가 없습니다.

  자동시작 해제:  python relay_agent.py --uninstall

===========================================================================
■ 5. 폰에서 앱으로 설치 & 사용
  1) 폰 브라우저(크롬/사파리)로  https://pmv.<서브도메인>.workers.dev  접속
  2) 브라우저 메뉴 → "홈 화면에 추가" → 앱 아이콘 생성(PWA 설치)
  3) 앱 실행 → 이메일/비밀번호 + 연결 코드(room, 릴레이와 동일) 입력 → "로그인 후 연결"
  4) "릴레이(집 PC) 기다리는 중…" → "연결됨" 이 되면 화면이 뜹니다.

■ 6. 조작
  - 탭=클릭, 드래그=마우스 이동, 두 손가락 위/아래=스크롤
  - 상단 "⌨ OFF"→"ON" 누르면 키보드 입력 전달(폰은 소프트 키보드가 올라옴)
  - "⛶" 전체화면

===========================================================================
■ 보안 메모
  - 연결 코드(room)와 HOST_KEY 가 접속 보호의 핵심입니다. 길고 무작위로, 노출 금지.
  - 보조 PC SECRET 은 릴레이 PC의 pal_relay_config.json 에 저장됩니다(이 PC 밖으로 안 나감).
  - Worker에 FIREBASE_PROJECT_ID(이미 설정됨)가 있으면 폰의 로그인 토큰도 서버에서 검증합니다.
