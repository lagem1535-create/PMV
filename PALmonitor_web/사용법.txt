[PALmonitor 웹 앱 - 사용법]

핸드폰/PC 브라우저에서 보조 PC의 화면을 보고 제어합니다.
기존 메인 클라이언트(main_client.py)와 똑같은 일을, APK 대신 "웹"에서 합니다.

구조:
  브라우저(로그인→화면보기)  <-- WebSocket -->  파이썬 릴레이(relay_server.py)  <-- TCP -->  보조 PC(auxiliary_server.py)

브라우저는 raw TCP(58712)에 직접 못 붙으므로, 파이썬 릴레이를 "경유"해서 연결합니다.
(요청하신 "파이썬 섭를 경유" 구조입니다.)

===========================================================================
■ 0. 준비물
  - 보조 PC: 기존처럼 auxiliary_server.py 가 실행 중이어야 함 (TCP 58712).
  - 릴레이를 돌릴 PC(보조 PC와 같은 네트워크면 아무거나, 보조 PC 자신이어도 됨):
      Python 3.9+ 와 pip
  - 새 Firebase 프로젝트 (아래 1번)

===========================================================================
■ 1. Firebase 새 프로젝트 만들기 (기존 AI톡/영수증 프로젝트 재사용 금지)
  1) https://console.firebase.google.com → "프로젝트 추가" 로 새 프로젝트 생성
  2) 좌측 "빌드 → Authentication → 시작하기"
     → "로그인 방법" 탭에서 "이메일/비밀번호" 사용 설정
     → "Users" 탭에서 로그인할 계정(이메일/비밀번호)을 추가
  3) 프로젝트 설정(⚙) → "내 앱"에서 웹 앱(</>) 추가
     → firebaseConfig 값(apiKey, authDomain, projectId ...)을 복사
  4) web/firebase_config.js 를 열어서, firebaseConfig 값에 그대로 덮어쓰기
     (databaseURL 은 알려주신 새 RTDB 주소가 이미 들어 있습니다)
  ※ "클라우드 플레이어에 firebase_config로 넣어둘게" 하신 그 자리가 이 파일입니다.

===========================================================================
■ 2. 릴레이 서버 실행 (릴레이 PC에서)
  pip install -r requirements.txt
  python relay_server.py
  → "ws://<릴레이PC_IP>:58080" 에서 대기합니다. 이 주소를 로그인 화면에 입력합니다.

  (권장, 토큰 검증 켜기) 로그인한 사람만 릴레이를 쓰게 하려면:
      Windows:  set FIREBASE_PROJECT_ID=내프로젝트ID  &&  python relay_server.py
      Mac/Linux: FIREBASE_PROJECT_ID=내프로젝트ID python relay_server.py
  특정 계정만 허용하려면:
      set PAL_ALLOWED_EMAILS=me@example.com,other@example.com

===========================================================================
■ 3. 웹 앱 열기
  방법 A) 릴레이 PC에서 정적 서버도 같이 실행:
      python serve_web.py
      → 폰/PC 브라우저에서  http://<릴레이PC_IP>:8000  접속
  방법 B) 웹 호스팅(Firebase Hosting, Netlify 등)에 web/ 폴더를 올려서 접속

===========================================================================
■ 4. 로그인 & 연결
  1) 이메일/비밀번호 입력 (1번에서 만든 계정)
  2) "연결 설정" 펼쳐서:
       - 릴레이 서버: ws://<릴레이PC_IP>:58080
       - 보조 PC 주소: 보조 PC의 IP (보조 PC에서 ipconfig 로 확인)
       - 보조 PC 포트: 58712 (기본)
       - 연결 암호: 보조 PC의 SECRET (기본 1234, 바꿨으면 그 값)
  3) "로그인 후 연결" → 화면이 뜨면 성공

===========================================================================
■ 5. 조작법
  - PC: 마우스로 이동/클릭/우클릭, 휠로 스크롤. 상단 "키보드 ON" 켜면 키 입력 전달.
  - 폰: 탭=클릭, 드래그=마우스 이동, 두 손가락 위/아래=스크롤.
         "키보드 ON" 누르면 소프트 키보드가 올라오고 입력이 전달됩니다.
  - 전체화면(⛶) 버튼으로 몰입 모드.

===========================================================================
■ 보안 메모
  - 연결 암호(SECRET)는 브라우저 메모리에만 두고 저장하지 않습니다(새로고침 시 재입력).
  - 인터넷에 공개하려면 릴레이 앞단에 HTTPS/WSS(리버스 프록시)를 두고,
    FIREBASE_PROJECT_ID 검증과 PAL_ALLOWED_EMAILS 허용 목록을 꼭 켜세요.
  - 같은 집/사무실 와이파이(내부망)에서만 쓸 거면 ws:// 로도 충분합니다.
